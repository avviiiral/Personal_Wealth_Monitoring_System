# Code of Conduct

## Our Commitment

The Personal Wealth Monitoring System (PWMS) project is intended to be a professional, respectful, and constructive environment for discussing software, engineering, financial-data handling, testing, documentation, and related technical topics.

We are committed to providing a welcoming environment for everyone who participates in the project.

## Expected Behavior

Participants are expected to:

- Be respectful and professional.
- Focus discussions on the technical issue or proposed change.
- Provide constructive and actionable feedback.
- Respect different technical approaches and opinions.
- Use clear and appropriate language.
- Keep discussions relevant to the project.
- Respect privacy and avoid sharing credentials, API keys, personal financial information, or other sensitive information.
- Report security vulnerabilities privately rather than publicly exposing them.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, threats, or personal attacks.
- Deliberately disruptive behavior.
- Trolling or repeated bad-faith participation.
- Publishing private or sensitive information without permission.
- Sharing credentials, tokens, passwords, financial records, or other confidential information.
- Introducing malicious code or intentionally harmful changes.
- Attempting to compromise project infrastructure, accounts, or user data.
- Any other behavior that would reasonably be considered inappropriate in a professional software project.

## Financial Information

PWMS deals with financial portfolio data. Contributors must take particular care not to expose:

- Real transaction files containing personal information.
- Brokerage or demat credentials.
- API keys or secrets.
- Personally identifiable information.
- Private portfolio information.
- Database files containing real user data.

Use synthetic or anonymized data when submitting examples, tests, screenshots, or bug reports.

## Enforcement

Project maintainers may remove, edit, or reject contributions and discussions that violate this Code of Conduct.

Serious or repeated violations may result in temporary or permanent restrictions on participation.

## Reporting

For conduct concerns, contact the project maintainer privately through the repository's available contact channels.

For security vulnerabilities, follow the process described in [`SECURITY.md`](./SECURITY.md).

## Scope

This Code of Conduct applies to project discussions, issues, pull requests, code reviews, documentation contributions, and other project-related interactions.

---

Thank you for helping keep PWMS professional, constructive, and secure.
